# 👻 Ghost سیکیورٹی ماڈیول
**PowerShell-تے مبنی Windows تے Azure سیکیورٹی سخت کرݨ آلا ٹول**

> **Windows اینڈپوائنٹ تے Azure ماحول لئی فعال سیکیورٹی سخت کرݨ۔** Ghost PowerShell-تے مبنی سخت کرݨ آلے فنکشن فراہم کریندا اے جیہڑے غیر ضروری سروس تے پروٹوکول نوں غیر فعال کر کے عام حملے دے ویکٹر نوں گھٹ کرݨ وچ مدد کر سڳدے نیں۔

## ⚠️ اہم اعلانات

**ٹیسٹنگ ضروری اے**: ہمیشہ پیداوار توں باہر ماحول وچ پہلے Ghost دی جانچ کرو۔ سروس نوں غیر فعال کرݨ نال جائز کاروباری کم متاثر ہو سڳدے نیں۔

**کوئی گارنٹی نہیں**: جدوں کہ Ghost عام حملے دے ویکٹر نوں نشانہ بنیندا اے، کوئی وی سیکیورٹی ٹول سارے حملیاں نوں روک نہیں سڳدا۔ ایہہ اک جامع سیکیورٹی حکمت عملی دا اک حصہ اے۔

**آپریشنل اثر**: کجھ فنکشن سسٹم دی کارکردگی نوں متاثر کر سڳدے نیں۔ تعیناتی توں پہلے ہر سیٹنگ دا احتیاط نال جائزہ گھنو۔

**پیشہ ورانہ جائزہ**: پیداواری ماحول لئی، سیکیورٹی پیشہ وراں نال مشورہ کرو تاں جو سیٹنگ تہاݙی تنظیم دی لوڑ نال میل کھاندیاں ہون۔

## 📊 سیکیورٹی دا منظر نامہ

Ransomware دا نقصان **2025 وچ $57 بلین** تک پہنچ گیا، تحقیق دسدی اے کہ بوہت سارے کامیاب حملے بنیادی Windows سروس تے غلط کنفیگریشن دا فائدہ چکدے نیں۔ عام حملے دے ویکٹر وچ شامل نیں:

- **90% ransomware واقعات** وچ RDP استحصال شامل اے
- **SMBv1 کمزوریاں** نے WannaCry تے NotPetya ورگے حملیاں نوں فعال کیتا
- **دستاویز میکرو** اک بنیادی میلویئر ترسیل دا طریقہ بݨدے رہندے نیں
- **USB-تے مبنی حملے** ایئر-گیپڈ نیٹ ورک نوں نشانہ بنیندے رہندے نیں
- **PowerShell دا غلط استعمال** حالیہ سالاں وچ نمایاں طور تے ودھیا اے

## 🛡️ Ghost سیکیورٹی فنکشن

Ghost **16 Windows سخت کرݨ آلے فنکشن** تے **Azure سیکیورٹی انضمام** فراہم کریندا اے:

### Windows اینڈپوائنٹ سخت کرݨ

| فنکشن | مقصد | خیالات |
|----------|---------|----------------|
| `Set-RDP` | ریموٹ ڈیسک ٹاپ رسائی نوں منظم کریندا اے | دور دراز انتظامیہ تے اثر پے سڳدا اے |
| `Set-SMBv1` | میراثی SMB پروٹوکول نوں کنٹرول کریندا اے | بوہت پرانے سسٹم لئی ضروری |
| `Set-AutoRun` | AutoPlay/AutoRun نوں کنٹرول کریندا اے | صارف دی سہولت تے اثر پے سڳدا اے |
| `Set-USBStorage` | USB سٹوریج ڈیوائس نوں محدود کریندا اے | جائز USB استعمال تے اثر پے سڳدا اے |
| `Set-Macros` | Office میکرو دی تکمیل نوں کنٹرول کریندا اے | میکرو-فعال دستاویزات تے اثر پے سڳدا اے |
| `Set-PSRemoting` | PowerShell ریموٹنگ نوں منظم کریندا اے | دور دراز انتظام تے اثر پے سڳدا اے |
| `Set-WinRM` | Windows ریموٹ مینجمنٹ نوں کنٹرول کریندا اے | دور دراز انتظامیہ تے اثر پے سڳدا اے |
| `Set-LLMNR` | ناں حل کرݨ دے پروٹوکول نوں منظم کریندا اے | عام طور تے غیر فعال کرݨ محفوظ اے |
| `Set-NetBIOS` | TCP/IP تے NetBIOS نوں کنٹرول کریندا اے | میراثی ایپلیکیشن تے اثر پے سڳدا اے |
| `Set-AdminShares` | انتظامی شیئر نوں منظم کریندا اے | دور دراز فائل رسائی تے اثر پے سڳدا اے |
| `Set-Telemetry` | ڈیٹا اکٹھا کرݨ نوں کنٹرول کریندا اے | تشخیصی صلاحیت تے اثر پے سڳدا اے |
| `Set-GuestAccount` | مہمان اکاؤنٹ نوں منظم کریندا اے | عام طور تے غیر فعال کرݨ محفوظ اے |
| `Set-ICMP` | پنگ ردعمل نوں کنٹرول کریندا اے | نیٹ ورک تشخیص تے اثر پے سڳدا اے |
| `Set-RemoteAssistance` | ریموٹ اسسٹنس نوں منظم کریندا اے | ہیلپ ڈیسک آپریشن تے اثر پے سڳدا اے |
| `Set-NetworkDiscovery` | نیٹ ورک دریافت نوں کنٹرول کریندا اے | نیٹ ورک براؤزنگ تے اثر پے سڳدا اے |
| `Set-Firewall` | Windows فائر وال نوں منظم کریندا اے | نیٹ ورک سیکیورٹی لئی اہم |

### Azure کلاؤڈ سیکیورٹی

| فنکشن | مقصد | ضروریات |
|----------|---------|--------------|
| `Set-AzureSecurityDefaults` | بنیادی Azure AD سیکیورٹی نوں فعال کریندا اے | Microsoft Graph اجازت |
| `Set-AzureConditionalAccess` | رسائی دی پالیسی نوں ترتیب دیندا اے | Azure AD P1/P2 لائسنسنگ |
| `Set-AzurePrivilegedUsers` | مراعات یافتہ اکاؤنٹ دا آڈٹ کریندا اے | گلوبل ایڈمن اجازت |

### انٹرپرائز تعیناتی دے اختیارات

| طریقہ | استعمال دا کیس | ضروریات |
|--------|----------|--------------|
| **براہ راست عملدرآمد** | ٹیسٹنگ، چھوٹے ماحول | مقامی ایڈمن حقوق |
| **گروپ پالیسی** | ڈومین ماحول | ڈومین ایڈمن، GP انتظام |

## 🔍 فنکشن تفصیلات

### بنیادی سخت کرݨ آلے فنکشن

#### نیٹ ورک سروس
- **RDP**: ریموٹ ڈیسک ٹاپ رسائی نوں بلاک کریندا اے یا پورٹ نوں بے ترتیب بنیندا اے
- **SMBv1**: میراثی فائل شیئرنگ پروٹوکول نوں غیر فعال کریندا اے
- **ICMP**: دوبارہ تشکیل لئی پنگ ردعمل نوں روکدا اے
- **LLMNR/NetBIOS**: میراثی ناں حل کرݨ دے پروٹوکول نوں بلاک کریندا اے

#### ایپلیکیشن سیکیورٹی
- **Macros**: Office ایپلیکیشن وچ میکرو تکمیل نوں غیر فعال کریندا اے
- **AutoRun**: ہٹاون یوگ میڈیا توں خودکار تکمیل نوں روکدا اے

#### دور دراز انتظام
- **PSRemoting**: PowerShell دور دراز سیشن نوں غیر فعال کریندا اے
- **WinRM**: Windows ریموٹ مینجمنٹ نوں بند کریندا اے
- **Remote Assistance**: ریموٹ اسسٹنس کنکشن نوں بلاک کریندا اے

#### رسائی دا کنٹرول
- **Admin Shares**: C$، ADMIN$ شیئر نوں غیر فعال کریندا اے
- **Guest Account**: مہمان اکاؤنٹ رسائی نوں غیر فعال کریندا اے
- **USB Storage**: USB ڈیوائس استعمال نوں محدود کریندا اے

### Azure انضمام
```powershell
# Azure ٹینینٹ نال جوڑو
Connect-AzureGhost -Interactive

# سیکیورٹی ڈیفالٹ نوں فعال کرو
Set-AzureSecurityDefaults -Enable

# مشروط رسائی نوں ترتیب دیو
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# مراعات یافتہ صارفین دا آڈٹ کرو
Set-AzurePrivilegedUsers -AuditOnly
```

### Intune انضمام (v2 وچ نواں)
```powershell
# Intune نال جوڑو
Connect-IntuneGhost -Interactive

# Intune پالیسی دے ذریعے تعینات کرو
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

## ⚠️ اہم خیالات

### ٹیسٹنگ ضروریات
- **لیبارٹری ماحول**: پہلے الگ تھلگ ماحول وچ ساریاں سیٹنگ دی جانچ کرو
- **مرحلہ وار تعیناتی**: مسئلے دی شناخت لئی بتدریج رول آؤٹ کرو
- **رول بیک پلان**: یقینی بناؤ کہ ضرورت پوݨ تے تبدیلیاں نوں پلٹ سڳدے او
- **دستاویزات**: ریکارڈ کرو کہ تہاݙے ماحول لئی کہڑیاں سیٹنگ کم کریندیاں نیں

### ممکنہ اثر
- **صارف پیداواریت**: کجھ سیٹنگ روزانہ دے ورک فلو نوں متاثر کر سڳدیاں نیں
- **میراثی ایپلیکیشن**: پرانے سسٹم نوں مخصوص پروٹوکول دی ضرورت پے سڳدی اے
- **دور دراز رسائی**: جائز دور دراز انتظامیہ تے اثر دا خیال رکھو
- **کاروباری عمل**: تصدیق کرو کہ سیٹنگ اہم کم نوں نہیں توڑدیاں

### سیکیورٹی حدود
- **گہرائی وچ دفاع**: Ghost سیکیورٹی دی اک تہہ اے، مکمل حل نہیں
- **جاری انتظام**: سیکیورٹی لئی مسلسل نگرانی تے اپڈیٹ دی لوڑ اے
- **صارف تربیت**: تکنیکی کنٹرول نوں سیکیورٹی آگاہی نال جوڑݨا چاہیدا اے
- **خطرے دا ارتقا**: نویں حملے دے طریقے موجودہ تحفظ نوں نظرانداز کر سڳدے نیں

## 🎯 حملے دے منظر نامے دی مثال

جدوں کہ Ghost عام حملے دے ویکٹر نوں نشانہ بنیندا اے، مخصوص روک تھام مناسب نفاذ تے ٹیسٹنگ تے منحصر اے:

### WannaCry-انداز دے حملے
- **تخفیف**: `Set-Ghost -SMBv1` کمزور پروٹوکول نوں غیر فعال کریندا اے
- **خیال**: یقینی بناؤ کہ کوئی میراثی سسٹم نوں SMBv1 دی ضرورت نہیں

### RDP-تے مبنی Ransomware
- **تخفیف**: `Set-Ghost -RDP` ریموٹ ڈیسک ٹاپ رسائی نوں بلاک کریندا اے
- **خیال**: متبادل دور دراز رسائی دے طریقیاں دی ضرورت پے سڳدی اے

### دستاویز-تے مبنی Malware
- **تخفیف**: `Set-Ghost -Macros` میکرو تکمیل نوں غیر فعال کریندا اے
- **خیال**: جائز میکرو-فعال دستاویزات تے اثر پے سڳدا اے

### USB-فراہم کردہ خطرات
- **تخفیف**: `Set-Ghost -USBStorage -AutoRun` USB فنکشنلٹی نوں محدود کریندا اے
- **خیال**: جائز USB ڈیوائس استعمال تے اثر پے سڳدا اے

## 📚 بہترین طریقے

### پہلے-تعیناتی
1. **موجودہ حالت دستاویز کرو**: تبدیلیاں توں پہلے `Get-Ghost` چلاؤ
2. **مکمل طور تے ٹیسٹ کرو**: غیر پیداواری ماحول وچ تصدیق کرو
3. **رول بیک پلان بناؤ**: ہر سیٹنگ نوں کیویں پلٹݨا اے جاݨو
4. **اسٹیک ہولڈر جائزہ**: یقینی بناؤ کہ کاروباری یونٹ تبدیلیاں نوں منظور کریندے نیں

### تعیناتی دے دوران
1. **مرحلہ وار نقطہ نظر**: پہلے پائلٹ گروپ وچ تعینات کرو
2. **اثر دی نگرانی کرو**: صارف دی شکایت یا سسٹم مسئلے دیکھو
3. **مسئلے دستاویز کرو**: مستقبل دے حوالے لئی کوئی وی مسئلہ ریکارڈ کرو
4. **تبدیلیاں دا اعلان کرو**: صارفین نوں سیکیورٹی بہتری دے بارے وچ مطلع کرو

### تعیناتی دے بعد
1. **باقاعدہ تشخیص**: سیٹنگ دی تصدیق لئی وقتاً فوقتاً `Get-Ghost` چلاؤ
2. **دستاویزات اپ ڈیٹ کرو**: سیکیورٹی کنفیگریشن نوں موجودہ رکھو
3. **تاثیر دا جائزہ گھنو**: سیکیورٹی واقعات لئی نگرانی کرو
4. **مسلسل بہتری**: خطرے دے منظر نامے دی بنیاد تے سیٹنگ ایڈجسٹ کرو

Ghost مفت استعمال، ترمیم تے تقسیم لئی MIT لائسنس دے تحت فراہم کیتا گیا اے۔

### سیکیورٹی اعلان
- **کوئی وارنٹی نہیں**: Ghost "جیویں اے" کسے قسم دی وارنٹی دے بغیر فراہم کیتا گیا اے
- **ٹیسٹنگ ضروری**: ہمیشہ پہلے غیر پیداواری ماحول وچ ٹیسٹ کرو
- **پیشہ ورانہ رہنمائی**: پیداواری تعیناتی لئی سیکیورٹی پیشہ وراں نال مشورہ کرو
- **آپریشنل اثر**: مصنفین کسے وی آپریشنل رکاوٹ لئی ذمہ دار نہیں
- **جامع سیکیورٹی**: Ghost اک مکمل سیکیورٹی حکمت عملی دا اک حصہ اے

### سپورٹ
- **GitHub مسئلے**: [بگ رپورٹ کرو یا فیچر دی درخواست کرو](https://github.com/jimrtyler/Ghost/issues)
- **دستاویزات**: تفصیلی مدد لئی `Get-Help <function> -Full` استعمال کرو
- **کمیونٹی**: PowerShell تے سیکیورٹی کمیونٹی فورم

**🔒 Ghost نال اپݨی سیکیورٹی پوزیشن نوں مضبوط کرو - پر ہمیشہ پہلے ٹیسٹ کرو۔**

```powershell
# قیاس آرائی دی بجائے تشخیص نال شروع کرو

```
